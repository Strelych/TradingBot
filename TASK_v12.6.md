## 2. Фиксы багов (приоритет 1, backend)

### 2.1 Size-bump вынести из analysis_loop в adapter.eval (60с)
В тик-цикле server.py — только чтение флага skip_size для readiness.
Никаких записей в pair_overrides и _save() на тике.

### 2.2 Bump по ЭФФЕКТИВНОму множителю
Эффектив = база x canary. Формула:
    canary = adapter.canary.get(symbol) or 1.0
    new_rm = min(2.0, required_rm / max(canary, 0.05))
Иначе bump вечный (база пишется, но эффектив падает из-за canary).

### 2.3 Детекция изменений + троттлинг
Запись ov["risk_mult"] и config_api._save() только при abs(new-old) > 1e-9.
Лог в adaptive_log не чаще 60с на (symbol, reason).

### 2.4 Fee-negative не бумпят
atr_pct < fee_floor -> сразу skip_size с троттлинг-логом, без bump.

### 2.5 Одна канарейка
canary = множитель режима (balanced=0.5). canary_fraction (0.25) применяется
ТОЛЬКО к пограничному решению (net_per_trade в зоне off_floor), не сверху на
режимную канарейку. x0.125 больше появляться не должно.

### 2.6 Исключения из risk_change_cooldown
Не применяется при: cold-start (n < min_sample), size-bump, первая смена
OFF->стратегия. Иначе бот заморожен на 6ч в мёртвой точке.

### 2.7 Хистерезис первого входа
Первая смена стратегии на cold-start — без стрика (сразу); далее
adapter_hysteresis_count циклов.

### 2.8 Авто-разблокировка stale OFF
Если set==AUTO и adapter_strategy=="OFF" не подтверждён split-валидацией
(обе половины окна < off_floor) за последние 2 eval — сбросить в рекомендацию.

### 2.9 Очистка спама при старте
В lifespan после init: DELETE FROM adaptive_log WHERE reason LIKE 'auto-size%'.

### 4.2 Шапка
Лого + "Bybit Scalper" + бейдж версии (из API) + бейдж config vN.
Чипы: WS (зелёный/красный), uptime, loop_errors.
Баланс со спарклайном за 24ч (SVG из daily /api/analytics).
START/STOP с подтверждением и анимацией состояния.

### 4.3 Стат-карточки (5)
Баланс / Сделок / Winrate / Net PnL / Дневной PnL.
Каждая: крупное число, дельта за период, мини-спарклайн, цвет по знаку.

### 4.4 Торговля (карточка пары) — новая структура
- Хедер: символ; цена live (flash зелёным/красным при тике); тренд-бейдж
  (▲ зелёный / ▼ красный / → серый); бейдж состояния HOLD/READY/В ПОЗИЦИИ.
- Чипы метрик: ATR%, спред, стены N, vol_rel — с tooltip (title).
- Стратегия: segmented control [AUTO|WALL|TREND|SWING|GRID|BREAKOUT|OFF]
  вместо select; режим: [агрессивный|сбалансированный|тайтовый|ручной].
- Readiness: прогресс-кольцо % готов + раскрывающийся чек-лист (компактные чипы).
- Стены: мини-бары bid/ask (топ-2 с каждой стороны): цена x объём (возраст с).
- Статус входа: степпер из 3 шагов (Ликвидность -> Мин.сумма -> Сигнал),
  каждый шаг зелёный/красный, справа причина ожидания.
- Если позиция/пендинг: блок с entry, TP/SL, live-PnL, кнопки Закрыть/Отменить.
- Рамка карточки: зелёная=готов, янтарная=ожидание, красная=блок/OFF.

### 4.5 Настройки — полная переработка
- Слева sticky-навигация по группам (Риск и сайзинг, WALL, TREND, SWING, GRID,

  кнопка "сброс" (к дефолту), маркер-точка если значение != дефолт.

- Sticky-бар снизу при dirty: [Сохранить N изменений] [Сбросить все].
- Pair overrides: таблица пара x (стратегия, режим, risk_mult, allowed_side,
  locked) с inline-редактированием, добавление/удаление строк, "очистить всё".
